# 💰 PowerMoon Salary Tracker

A modern, intuitive salary tracking and financial management tool built with [Next.js](https://nextjs.org) for Power Moon TechMed Pvt.Ltd, Bhubaneswar, Odisha.

## ✨ Features

- 📊 Real-time salary analytics and visualizations
- 🎯 Budget planning and expense tracking
- 🔐 Secure data storage
- 📱 Fully responsive design

> 📊 Update - 0.2.0

- Fixed minor bugs

## 🛠️ Built With

- **Framework**: [Next.js](https://nextjs.org) with TypeScript
